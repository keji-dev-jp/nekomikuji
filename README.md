# ねこみくじ 🐱

スワイプ型おみくじゲーム。猫カードをスワイプして今日の運勢を引こう！

## 遊び方
1. 猫カードを左右にスワイプ
2. 結果（大吉・中吉・小吉・吉・末吉）が表示される
3. Xシェア・もう一回引くが可能（1日3回まで）

## 機能
- 🐱 オリジナルSVG猫イラスト（スワイプで表情が変わる）
- 📅 日替わりおみくじ（1日同じ結果・localStorage管理）
- 🔁 1日3回まで引ける
- 📴 オフライン対応（Service Worker）
- 📲 PWA対応（ホーム画面に追加可能）
- 🐦 Xシェアボタン付き
